Real Notification Delivery Mechanism & Setup

StudyPath enforces transparent notification tracking:

  • Active In-Browser & Desktop Alerts: When permission is granted, StudyPath uses the standard Web Notifications API and Web Audio API to alert you with desktop popups and audio chimes while StudyPath is running.
  • Offline / Closed-Browser Delivery Requirements: Delivering notifications when your browser is completely closed requires an external email service (configured via SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS) or a Web Push server (configured via VAPID_PUBLIC_KEY and VAPID_PRIVATE_KEY) running with a scheduled cron worker.
  • Integrity Guarantee: StudyPath only marks reminders as "Active & Scheduled" for channels that are genuinely configured on your device.

Intelligent "Next Up" Spotlight

The top card evaluates deadline proximity and priority weights to immediately answer “What should I work on next?”. Overdue and pressing items automatically bubble to the head of the queue.

Stack (LIFO) O(1) Undo/Redo

Full-Stack Undo & Redo

Every mutation pushes an invertible delta onto undoStack. When popped, the reverse action is applied locally and synchronized with the backend database.

undoStack.push({ type: 'DELETE', item, index })

Tokenizes your query across titles, course subjects, and personal notes. Filters evaluate instantaneously with zero layout thrashing.
